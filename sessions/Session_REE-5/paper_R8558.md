# Virtual-real interaction in geospatial twin-oriented marine GIS data model

**Author Information**  
Cunjin Xue<sup>1</sup>, Qingrui Liu<sup>1</sup>


<sup>1</sup> Aerospace Information Research Institute, Chinese Academy of Sciences  



## Abstract

This study proposes a virtual-real interaction-oriented marine GIS spatiotemporal data model termed the Virtual-Real Interaction-oriented Marine Data Model (VRIO-MDM), based on a tripartite framework for geospatial twin systems. Through semantic decoupling, VRIO-MDM systematically defines eight core elements across twin spaces: three components in oceanic physical space (marine entities, marine data, execution units) and five corresponding counterparts in digital space (twin entities, twin data, virtual execution units, marine models, marine knowledge), thereby establishing a clear demarcation between physical and digital domains. Building upon these eight elements, VRIO-MDM formulates relational frameworks that characterize physical space, twin space, and their bidirectional interactions, creating an integrated relationship system spanning virtual modeling to autonomous evolution. Thus, VRIO-MDM effectively encapsulates the interactive closed-loop encompassing perception, analysis, and intervention. Technically, VRIO-MDM employs a geospatial knowledge graph to develop a graph-based expression framework while implementing a graph-object hybrid storage architecture integrating graph databases with object-relational databases. This implementation utilizes Neo4j for efficient management of complex semantic relationships among objects and PostgreSQL for robust storage of large-scale geospatial data, with geographic object unique identifiers facilitating cross-layer data association. The dual-architecture configuration effectively balances requirements for sophisticated interaction reasoning with high-volume geospatial data processing capabilities. This study presents an elemental decoupling framework for "physical-digital" geospatial twins and establishes a five-tiered relational framework spanning the complete "perception-cognition-intervention" cycle, thereby advancing spatiotemporal modeling methodologies within marine twin environments. Furthermore, the proposed graph-object integrated hybrid storage architecture, based on the design principle of storing relationships in graph databases and objects in object databases, effectively addresses performance limitations inherent to monolithic storage paradigms in geospatial twin implementations.
