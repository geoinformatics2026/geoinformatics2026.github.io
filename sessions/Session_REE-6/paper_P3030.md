# Estimation of forest LAI at the plot scale by using LESS simulation for sample augmentation

**Author Information**  
Hongtao Wang<sup>1</sup>, Zexiang Ren<sup>1</sup>


<sup>1</sup> Henan Polytechnic University  



## Abstract

Accurately inverting leaf area index (LAI) plays a crucial role in monitoring vegetation growth status. This study proposed a simulation-based sample augmentation strategy that integrates UAV data with the LESS 3D radiative transfer model to estimate LAI using machine learning methods. Firstly, simulated forest scenes were generated using the LESS model, in which leaf optical properties were constrained by the PROSAIL model in combination with measured UAV multispectral data. Meanwhile, the LESS model was used to generate 3D scenes based on UAV point cloud data, thereby obtaining the LAI for each scene. Subsequently, the simulated samples generated by LESS were integrated into the measured dataset to form an augmentation dataset. Finally, the spectral and point cloud features of the measured and simulated scenes were combined to train a machine learning regression model under augmented sample conditions. The results showed: (1) For field-measured samples, CatBoost achieved the highest precision by integrating spectral and point cloud features $(R^{2}=0.62$, $RMSE=0.57)$. (2) After applying the sample augmentation strategy, the accuracy of the LAI estimation model was further improved $(R^{2}=0.89, $ RMSE-0.4). This confirms the feasibility of estimating plot scale LAI by integrating 3D radiative transfer models and UAV data under sample augmentation conditions.
