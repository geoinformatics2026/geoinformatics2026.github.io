## Abstract

Bike-sharing operators require accurate prediction of user return stations to enhance service efficiency. However, traditional statistical methods face two major challenges: sparse individual user data making it difficult to identify behavioral patterns, and excessively high computational costs when considering all condition combi- nations. This study proposes a hybrid deep learning architecture to address these issues: employing conditional Generative Adversarial Networks (CGAN) to predict return station orientations with group behavioral patterns when data is insufficient, and utilizing Convolutional Neural Networks (CNN) to construct user characteristic prediction models, thereby reducing manual observation costs. Validation based on data from 8 rental stations demonstrates the feasibility of this architecture. Experimental findings reveal:(1) For users with fixed time periods and high-frequency stations, CNN can accurately predict their characteristics; (2) CGAN effectively compensates for CNN's shortcomings when data is sparse. This study provides bike-sharing operators with a scalable and efficient prediction solution, offering significant practical value for improving service efficiency.
