# An AI-powered Location-based Recommendation System for Personalised Urban Mobility

**Author Information**  
Devika Yesodharan Devaprabha<sup>1</sup>, Jia Wang<sup>1</sup>


<sup>1</sup> University of Greenwich  



## Abstract

Abstract The increasing availability of heterogeneous spatial and contextual data sources presents both an opportunity and a challenge for location-based decision support systems. This paper presents an AI-powered recommendation system designed to facilitate personalised urban mobility while enhancing users' sense of place. The proposed system integrates multiple open data sources through a unified fusion pipeline that aligns multiple data inputs to support location-based recommendations. Data sources include UK police crime statistics, Ticketmaster event listings, OpenStreetMap points of interest (POIs), online news articles, and routing data. The proposed system architecture comprises four components: a dynamic scoring module for safety and popularity assessment, a conversational AI interface supporting natural language location queries, a personalised recommendation engine informed by user interaction behaviour, and a journey planner that provide users with ranked routes based on safety. The result confirms real-time responsiveness across all four components and contextually meaningful outputs across diverse query types. The key contributions of this work are: (i) a scalable, timely spatial data fusion pipeline for multi-source urban data; and (ii) an Al-augmented decision support framework that promotes more informed and safer urban mobility.
