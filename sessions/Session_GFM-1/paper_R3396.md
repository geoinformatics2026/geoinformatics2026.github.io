# Geo-Informatics Driven by Large Language Models: Key Technologies and Benchmarks for GIS Spatial Analysis Code Generation

**Author Information**  
Shuyang Hou<sup>1</sup>, Huayi Wu<sup>1</sup>


<sup>1</sup> Wuhan University  



## Abstract

Large Language Models (LLMs) have revolutionized general code generation but face critical bottlenecks in GIS spatial analysis tasks—low accuracy, severe hallucinations, insufficient domain knowledge, and poor workflow orchestration, especially on platforms like Google Earth Engine (GEE). This work presents a comprehensive technical system for LLM-driven GIS code generation, addressing three core challenges: 1) Developing benchmark suites (AutoGEEval, AutoGEEval++) with 6,365+ test cases to enable automated evaluation; 2) Building specialized geospatial knowledge bases (Geo-FuB, GEE-OPs) with 290k+ scripts and a fine-tuned model (GeoCode-GPT) to mitigate hallucinations; 3) Proposing workflow orchestration frameworks (CoP, GeoCogent, GeoColab) for zero-shot performance improvement. Experiments show our solutions significantly boost executability and correctness across multiple GIS platforms and languages. We also release an open leaderboard and application platform, advancing autonomous GIS and supporting real-world tasks like environmental monitoring and urban planning.
