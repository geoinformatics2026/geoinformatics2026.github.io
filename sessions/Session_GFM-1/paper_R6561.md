# Geospatial modeling workflow knolwledge empowered geospatial code generation

**Author Information**  
Jianyuan Liang<sup>1</sup>, Huayi Wu<sup>1</sup>


<sup>1</sup> LIESMARS, Wuhan University  



## Abstract

Recent advances in large language models (LLMs) provide new opportunities for natural language–driven geospatial modeling. However, general LLMs lack sufficient understanding of geospatial modeling workflow knowledge, making it difficult to generate structurally coherent and logically correct geospatial code.To address this issue, this study introduces the concept of a geospatial modeling workflow knowledge network, GeoMK-Net, which organizes functional modules, input–output entities, and their dependencies in geospatial modeling processes. An LLM-driven knowledge extraction method is further proposed to automatically extract workflow knowledge from heterogeneous geospatial modeling scripts. Based on this knowledge, a graph-aware code generation method is developed to guide LLMs using modeling workflow subgraphs as structural priors. By incorporating modeling workflow knowledge into the LLM generation process, the proposed framework establishes a knowledge-driven mechanism linking modeling requirements, workflow structures, and executable code, which provides a new pathway for natural language–driven geospatial modeling.



Keywords: geospatial code generation,  workflow knowledge,  geospatial modeling,  graph RAG,  LLM
