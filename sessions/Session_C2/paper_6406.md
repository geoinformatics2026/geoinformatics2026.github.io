#  Vague Geographic Entity Localization Method Based on  Crowdsourced Path Descriptions

**Author Information**  
Xiang Liu<sup>1</sup>, Xiawei Chen<sup>1</sup>, Yi Long<sup>1</sup>


<sup>1</sup> Nanjing Normal University  



## Abstract

Social media texts contain rich geospatial knowledge, offering a valuable new data source for geographic information extraction. However, existing studies predominantly focus on location extraction based on static descriptive spatial knowledge, while methods for localizing vague geographic entities from dynamic procedural spatial knowledge remain largely underexplored. To address this gap, this study targets crowdsourced multi-path textual descriptions of a common destination entity contributed from diverse origins, and proposes a novel multi-path simulation and vague geographic entity localization framework grounded in procedural text analysis.By systematically examining the spatial expression patterns inherent in social media texts, large language models (LLMs) are employed to deconstruct path representations and map them onto real-world geographic spaces, enabling fine-grained path reconstruction. Differentiated fuzzy region modeling strategies are further designed to accommodate varying combinations of descriptive elements, and the target entity's location is inferred through integrated multi-path reconstruction.Experimental results demonstrate that the proposed method effectively reconstructs complex path descriptions from social media data and achieves precise localization of target entities. This work advances the theoretical understanding of procedural spatial knowledge and offers new methodological insights for the development of geospatial analytical frameworks.



Keywords: Procedural spatial knowledge,  Path description reconstruction,  Vague geographic entity localization,  Fuzzy region modeling,  Large language models(LLMS),  Crowdsourced social media text
