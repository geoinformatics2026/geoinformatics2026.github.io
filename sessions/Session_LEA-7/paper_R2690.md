# Multi-Scale Deep Learning Extraction of Farmland Shelterbelts Integrating Phenological Differences and Texture Features Using Sentinel-2 Imagery

**Author Information**  
Hongyan Cai<sup>1</sup>


<sup>1</sup> 11A, Datun Road, Chaoyang District, Beijing  



## Abstract

Farmland shelterbelts play a critical role in agricultural ecological security and cropland quality improvement. However, their narrow and linear spatial patterns pose significant challenges for conventional pixel-based classification approaches. In this study, we developed an automated shelterbelt extraction framework by integrating phenological differences and spatial texture features using Sentinel-2 multispectral imagery. First, random sampling and visual interpretation were conducted to construct shelterbelt and cropland reference samples. Monthly NDVI time series were analyzed to identify key phenological periods with maximum inter-class separability. Second, feature combinations including spectral bands, NDVI, and Local Binary Pattern (LBP) texture indices were constructed, and machine learning models (SVM and Random Forest) were evaluated. Results show that incorporating texture features improved classification accuracy from 83.6% to 94.6%, significantly enhancing the discrimination of narrow linear structures. Finally, a multi-branch convolutional neural network with multi-scale feature fusion was designed to address spatial context limitations in single-branch models. The optimized deep learning model achieved an overall accuracy of 98%, substantially outperforming traditional feature-based approaches while reducing reliance on auxiliary cropland datasets. The proposed framework provides a robust and scalable solution for large-area shelterbelt mapping and offers methodological support for precision agricultural landscape monitoring.
