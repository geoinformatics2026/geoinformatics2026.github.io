# Agent Workflow Based Intelligent Mapping Method for Natural Disaster Emergency Response

**Author Information**  
Weiyao Guo<sup>1</sup>, An Zhang<sup>1</sup>, Yi Cao<sup>1</sup>


<sup>1</sup> Institute of Geographic Sciences and Natural Resources Research, Chinese Academy of Sciences  



## Abstract

Traditional cartographic workflows are often complex     and inefficient, making them difficult to adapt to     rapidly evolving disaster scenarios, continuously     updated multi-source data, and the strict timeliness     and standardization requirements of emergency map     production. Although GeoAI approaches, including     generative artificial intelligence, have shown     potential in automated map generation, significant     limitations remain in disaster mapping tasks. In     particular, current approaches struggle to determine     appropriate map themes from available cartographic data     and to select suitable representation methods and     visual variables for effective map design.     To address these challenges, this study proposes an     intelligent emergency mapping method for natural     disasters based on an agent workflow. By interpreting     cartographic task requirements expressed in natural     language and autonomously selecting appropriate tools,     the proposed approach constructs a knowledge-driven     agent workflow designed for complex disaster scenarios.     This workflow enables automated generation of emergency     maps from natural language instructions.     First, typical disaster map cases, cartographic     specifications, and thematic elements are integrated     using intelligent algorithms to build a structured and     machine-readable cartographic knowledge base. Next,     several functional tools are developed, including a map     theme matching tool based on natural language     processing models, a map style recommendation tool     based on representation-method similarity and color     similarity, and a cartographic visualization tool for     map generation. These components are integrated within     an agent workflow to achieve cross-modal mapping from     natural language instructions to map outputs.     To evaluate the effectiveness of the proposed approach,     an agent workflow was implemented on the Coze platform     and applied to natural disaster emergency mapping tasks     driven by natural language input. Experimental results     demonstrate that the proposed method provides a     practical framework for intelligent disaster     cartography and shows promising potential for improving     the efficiency and adaptability of emergency map     production.



Keywords: GeoAI,  Disaster Emergency Cartography,  Agent,  Intelligent Cartography
