# A Spatiotemporal Data Field-Driven UAV Path Planning Framework for Urban High-Density Crowd Hotspot Monitoring

**Author Information**  
Mu Duan<sup>1</sup>, Chuli Hu<sup>1</sup>, Ke Wang<sup>1</sup>


<sup>1</sup> China University of Geosciences, Wuhan  



## Abstract

Timely identification and monitoring of urban high-density crowd hotspots are essential for proactive urban governance and public safety management. However, a systematic coupling between real-time event detection and adaptive UAV deployment remains insufficiently explored. This study proposes a demand-driven UAV path planning framework for dynamic hotspot monitoring. A unified spatiotemporal event detection model is constructed by integrating social media data streams with an ST-DBSCAN-based adaptive clustering approach to capture evolving crowd events. A City Grid Heat Value model, grounded in spatiotemporal data field theory, is further developed to quantify dynamic hotspot influence intensity. By integrating dynamic heat metrics with static factors (population density and sensor coverage) through a hybrid AHP–TOPSIS decision framework, regional monitoring demand levels are evaluated. To achieve efficient multi-UAV coordination under resource constraints, an improved APF-D3QN algorithm is designed, incorporating demand-driven gravitational attraction and inter-UAV repulsion mechanisms within a multi-agent reinforcement learning architecture. A case study in Hongshan District, Wuhan demonstrates that the proposed framework accurately captures hotspot distributions and significantly improves monitoring coverage and resource utilization compared to baseline D3QN. The results validate the effectiveness of the proposed closed-loop perception–decision–deployment paradigm for proactive urban safety management.
